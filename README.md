application alarm build with vibe-coding

# 标准
1. prompt质量水平
2. 页面效果完成度
3. 项目复杂程度
4. 代码质量，可维护性

# 提交规范
1. 分支命名 pure-vibe-coding-xxx
2. commit 规范参照<type>(<scope>): <subject>
eg:
    feat(auth): add GitHub login
    fix(api): handle empty response
    docs(readme): update setup instructions
    refactor(parser): simplify token flow
    test(strategy): add dual momentum coverage
    chore(deps): bump pandas to 2.2
